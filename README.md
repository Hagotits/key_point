# Skeleton Keypoint Labeler

브라우저에서 동작하는 스켈레톤 키포인트 어노테이션 도구입니다.\
프로젝트마다 기준 스켈레톤(키포인트 + 연결선)을 직접 그려 정의하고, 업로드한 이미지에 바운딩 박스를 그리면 그 안에 스켈레톤이 자동으로 배치됩니다.\
이후 각 키포인트의 위치와 가시성(보임 / 가려짐 / 없음)을 다듬어 JSON으로 내보냅니다.\

모든 처리는 브라우저 안에서 이루어집니다. 이미지는 서버로 업로드되지 않고, 작업 내용은 IndexedDB에 자동 저장되어 새로고침 후에도 이어서 작업할 수 있습니다.

## 주요 기능

- **커스텀 스켈레톤 정의** - 캔버스를 클릭해 키포인트를 추가하고, 클릭 순서대로 연결선이 이어집니다. 가지 치기, 선 삭제, 포인트 이동/이름 변경을 지원합니다.
- **박스 드래그로 스켈레톤 자동 배치** - 드래그 방향(4방향 스냅)에 따라 템플릿이 회전해서 배치되므로, 드래그를 시작한 쪽이 스켈레톤의 위쪽(예: 머리)이 됩니다.
- **3단계 가시성 관리** - `2` 보임 / `1` 가려짐(추정) / `0` 없음. `v=0`인 키포인트는 좌표가 `null`로 저장되며, "위치 다시 지정"으로 언제든 되살릴 수 있습니다.
- **줌 · 패닝 · 포인트 크기 조절** - 조밀한 키포인트도 확대해서 정밀하게 찍을 수 있습니다.
- **객체 복사** — 비슷한 자세의 객체를 복제해 위치만 조정하면 됩니다.
- **실행 취소 / 다시 실행** - 최대 100단계 (`Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z`).
- **자동 저장 및 이어서 하기** - 작업 상태가 IndexedDB에 저장되어, 시작 화면의 "최근 세션"에서 이미지까지 그대로 복원합니다.
- **JSON 내보내기 / 불러오기** - 내보내기 전에 가시성과 좌표의 정합성을 검증합니다.
- **키보드 접근성** - 가시성 컨트롤은 `radiogroup`으로 노출되며 방향키로 조작할 수 있고, 좁은 화면(375px)에서도 가로 스크롤 없이 한 열로 재배치됩니다.

## 시작하기

요구 사항: Node.js 20 이상 (테스트는 내장 `node --test` 러너를 사용합니다).

```bash
npm install
npm run dev      # 개발 서버 실행
```

| 명령어 | 설명 |
|--------|------|
| `npm run dev` | Vite 개발 서버 (HMR) |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run lint` | Oxlint 검사 |
| `npm test` | 유닛 테스트 (`test/`) |

## 사용 흐름

1. **프로젝트 생성** — 프로젝트 이름을 입력합니다. 이전 작업이 있다면 "최근 세션"에서 바로 이어서 할 수 있습니다.
2. **기준 스켈레톤 그리기** — 캔버스를 클릭해 포인트를 추가합니다. 선택된 포인트에서 다음 포인트로 선이 자동으로 이어지고, 이미 찍은 포인트를 클릭하면 그 지점부터 가지를 칠 수 있습니다.
3. **이미지 업로드** — 개별 파일 또는 폴더 단위로 업로드합니다. 파일명 기준으로 자연 정렬됩니다.
4. **라벨링** — 이미지 위에서 드래그해 박스를 만들면 스켈레톤이 배치됩니다. 각 포인트를 드래그해 위치를 맞추고, 보이지 않는 부위는 가시성을 조정합니다.
5. **내보내기** — 좌측 하단 "JSON 내보내기"로 `{프로젝트명}_annotations.json`을 저장합니다.

## 단축키

### 라벨링 화면

| 조작 | 동작 |
|------|------|
| 드래그 | 바운딩 박스 그리기 (시작 지점이 스켈레톤 위쪽) |
| `Shift` + 드래그 | 겹친 객체 위에 새 박스 그리기 |
| 마우스 휠 | 줌 인 / 아웃 |
| `Space` + 드래그, 휠 버튼 드래그 | 화면 이동 |
| `1` / `2` / `3` | 선택한 키포인트를 없음 / 가려짐 / 보임으로 설정 (넘패드 지원) |
| `V` | 선택한 키포인트의 가시성 순환 |
| `Delete` / `Backspace` | 키포인트 선택 시 → 없음(`v=0`) 처리 · 객체 선택 시 → 객체 삭제 |
| `Esc` | 선택 및 위치 재지정 모드 해제 |
| `Cmd/Ctrl` + `Z` | 실행 취소 |
| `Cmd/Ctrl` + `Shift` + `Z` | 다시 실행 |

### 스켈레톤 정의 화면

| 조작 | 동작 |
|------|------|
| 빈 곳 클릭 | 포인트 추가 (선택된 포인트에서 선 자동 연결) |
| 포인트 클릭 | 그 점을 다음 선의 시작점으로 선택 (가지 치기) |
| 선 클릭 | 선 삭제 |
| 포인트 드래그 | 위치 이동 |
| `Esc` | 연결 끊고 새로 시작 |
| `Delete` / `Backspace` | 선택한 포인트 삭제 |

## 내보내기 형식

좌표는 이미지 원본 픽셀 기준이며, `bbox`는 `[x, y, width, height]`입니다.

```json
{
  "project": "사람 포즈 라벨링",
  "keypoints": ["head", "neck", "l_shoulder"],
  "visibility": {
    "0": "not labeled, x/y null",
    "1": "occluded, estimated",
    "2": "visible"
  },
  "skeleton": [["head", "neck"], ["neck", "l_shoulder"]],
  "images": [
    {
      "name": "frame_001.jpg",
      "width": 1920,
      "height": 1080,
      "annotations": [
        {
          "geometryVersion": 2,
          "bbox": [420, 160, 300, 700],
          "keypoints": [
            { "name": "head", "x": 560, "y": 210, "v": 2 },
            { "name": "neck", "x": 562, "y": 300, "v": 1 },
            { "name": "l_shoulder", "x": null, "y": null, "v": 0 }
          ]
        }
      ]
    }
  ]
}
```

내보내기 전 검증 규칙:

- `v=0`인데 좌표가 남아 있거나, `v≥1`인데 좌표가 없으면 저장이 차단되고 문제 항목이 표시됩니다.
- 모든 키포인트가 `v=0`인 객체가 있으면 실수 가능성을 알리고 저장 여부를 확인합니다.

불러오기는 이미지 이름(경로 제외 파일명 포함)으로 매칭합니다.\
`v` 필드가 없는 예전 파일은 좌표가 있으면 `v=2`, 없으면 `v=0`으로 해석하고, 현재 프로젝트에 정의되지 않은 키포인트는 무시합니다.

## 프로젝트 구조

```
src/
├── App.jsx                     # 화면 전환 (project → setup → label)
├── components/
│   ├── ProjectSetup.jsx        # 프로젝트 생성 / 최근 세션 복원
│   ├── LabelSetup.jsx          # 기준 스켈레톤 정의 + 이미지 업로드
│   ├── Labeler.jsx             # 라벨링 화면 (캔버스 · 인스펙터)
│   └── SessionAutosave.jsx     # 디바운스 자동 저장 + 상태 표시
├── annotationGeometry.js       # 구버전 좌표계 보정 (geometryVersion)
├── duplicateInstance.js        # 객체 복사 (이미지 경계 안쪽으로 오프셋)
├── dragVisibility.js           # 드래그 중 표시할 객체 선택
├── history.js                  # 실행 취소 / 다시 실행 스택
├── pointerInteraction.js       # 포인터 입력 → pan / draw / edit 판정
├── sessionStore.js             # IndexedDB 세션 저장소
├── visibility.js               # 가시성 단축키 및 상태 변경
└── utils.js                    # 이미지 로딩, 색상 팔레트, 크기 계산
test/                           # node --test 유닛 테스트
```

디자인 토큰과 컴포넌트 규칙은 [DESIGN.md](./DESIGN.md)에 정리되어 있습니다.

## 좌표 호환성

초기 버전은 화면 배치 기준으로 좌표를 저장해 일부 어노테이션이 어긋날 수 있었으나 현재는 이미지 원본 좌표계(`geometryVersion: 2`)를 사용하며, 예전 데이터가 감지되면 인스펙터에 **"이전 위치 보정"** 버튼이 나타납니다.\
보정 결과는 `Cmd/Ctrl+Z`로 되돌릴 수 있습니다.

## 기술 스택

React 19 · Vite 8 · Oxlint · Node.js 내장 테스트 러너.
런타임 의존성은 React와 React DOM뿐이며, 상태 관리·캔버스·저장소 로직은 모두 직접 구현되어 있습니다.
